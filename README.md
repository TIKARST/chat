# Qwen3.5-9B 极简本地联网工作台

基于 **Ollama + Gradio + Exa** 构建的轻量化本地大模型交互工作台，专为 8GB 显存显卡（如 RTX 2060 Super）优化，支持实时联网检索与异常静默降级。

## ✨ 核心特性

- **显存友好锁定**：强制限制上下文长度为 `4096`（`num_ctx: 4096`），并自动截断保留最近 4 轮对话历史，8G 显存流畅运行不爆显存。
- **实时联网检索**：集成 Exa Search API，一键勾选即可获取最新网页信息辅助回答。
- **双重容错与静默降级**：联网请求内置 6 秒超时保护，遇到网络波动或未配置密钥时自动无缝切换为纯本地推理，对话绝不卡死。
- **流式丝滑输出**：原生支持逐字流式响应，交互体验流畅。

## 🛠️ 环境准备与启动

### 1. 安装 Python 依赖
```bash
pip install gradio exa-py python-dotenv requests
2. 配置模型与环境变量
确保本地已启动 Ollama 并拉取对应模型：

Bash
ollama run qwen3.5:9b
在项目根目录创建 .env 文件，填入你的 Exa API Key（如不需要联网功能可跳过此步）：

程式碼片段
EXA_API_KEY=你的_EXA_API_KEY
3. 启动工作台
Bash
python APP.py
启动后，在浏览器打开终端提示的本地地址（默认 http://127.0.0.1:7860）即可开始使用。
